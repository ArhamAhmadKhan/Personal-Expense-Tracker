# Personal Expense Tracker and Budget Management System

## Project Overview
A web-based application developed using Python, Flask, and MySQL to manage personal income and expenses.

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- Chart.js

## Main Features
1. Dashboard showing total income, expenses, and available balance.
2. Add income and expense transactions.
3. Categorize transactions.
4. Edit existing transactions.
5. Delete transactions.
6. Visualize expenses using a doughnut chart.
7. Store transaction records in MySQL.

## Database Tables
- Users
- Categories
- Transactions
- Budgets

## How to Run
1. Install Python and MySQL.
2. Import `expense_tracker.sql` into MySQL.
3. Install dependencies using `pip install -r requirements.txt`.
4. Configure the MySQL connection in `database.py`.
5. Run `python app.py`.
6. Open http://127.0.0.1:5000 in a browser.

## Project Purpose
This project demonstrates database connectivity, relational database design, SQL operations, CRUD functionality, and web application development.
